Ключ OpenAI нельзя класть в код страницы: его увидит любой посетитель. Поэтому чат отправляет переписку вашей функции, функция добавляет ключ, спрашивает OpenAI и передает ответ обратно по мере генерации.

  1. Скачайте код функции. Файлы worker.js и wrangler.toml лежат на GitHub. В wrangler.toml впишите адрес своего сайта в ALLOWED_ORIGINS.
  2. Войдите в Cloudflare. Бесплатного аккаунта достаточно. 
    npm i -D wrangler@latest
npx wrangler login
  3. Сохраните ключ в секретах Cloudflare. Wrangler спросит значение ключа и предложит создать функцию, если ее еще нет. 
    npx wrangler secret put OPENAI_API_KEY
  4. Опубликуйте функцию. Wrangler напечатает адрес вида https://onpress-chat.ваш-аккаунт.workers.dev. 
    npx wrangler deploy
  5. Вставьте адрес в чат.

Функция пропускает только запросы с адресов из ALLOWED_ORIGINS, ограничивает длину сообщений и истории и может ограничить число сообщений в минуту с одного IP. За ответы модели платите вы по тарифу OpenAI.
